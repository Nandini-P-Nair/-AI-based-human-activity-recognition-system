What is this System?

This is an AI-based intelligent video surveillance platform built specifically for activity recognition and security management in parks. When an AI camera is deployed on a footpath, the system automatically classifies observed activities as authorized or unauthorized.

Only walking and running are permitted on monitored footpaths. Any other activity is flagged as unauthorized and highlighted in red, while permitted activities are shown in green — giving administrators instant, color-coded clarity.

How the System Works

Video data is collected from diverse park scenarios and annotated to categorize actions into authorized (walking, running) and unauthorized activities. Frames are preprocessed to handle noise, incomplete annotations, and inconsistencies before feeding into the model.

A YOLO-based object detection model is trained, evaluated, and optimized to distinguish between activity classes in real-time. The result is a robust, accurate system validated across various park scenarios and lighting conditions.

Project Modules

Four core development phases powering the platform

Data Collection & Preprocessing

Video data collected from diverse park scenarios is annotated into authorized and unauthorized classes, then preprocessed to address noise, incomplete annotations, and inconsistencies before model training.

Model Training & Evaluation

YOLO-based object detection models are trained to identify walking, running, and other actions — then evaluated and optimized for accuracy in distinguishing authorized from unauthorized activities.

UI Development

A user-friendly interface designed to let park administrators upload video streams, view color-coded activity results (green for authorized, red for unauthorized), and manage surveillance efficiently.

Testing & Bug Fixing

Comprehensive testing using holdout datasets ensures robust model performance across variable park scenarios, lighting conditions, and crowd densities — with iterative bug fixing for production stability.

Activity History Log

Every analysed video stream is logged with its classification result, giving administrators a complete audit trail for incident review, reporting, and pattern analysis over time.

Secure & Role-Based Access

All video data is processed securely with role-based authentication ensuring only authorized park administrators can access surveillance results, history logs, and system settings.
